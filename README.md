# Deni Jaya Las — website jasa las dan furnitur custom

Website katalog inspirasi dan formulir permintaan yang membuka WhatsApp dengan pesan terisi. Nomor WhatsApp saat ini dikonfigurasi di `app/page.tsx`, menggunakan format internasional tanpa tanda `+`.

## Menjalankan

```sh
npm ci
npm run dev
```

Deskripsi layanan dan foto saat ini adalah contoh; ganti dengan foto hasil pekerjaan dan layanan yang sesuai sebelum dipublikasikan. Foto berasal dari Unsplash. Harga dan waktu pengerjaan dibahas langsung dengan pelanggan.

Model 3D meja besi adalah ilustrasi inspirasi, bukan produk dengan ukuran atau harga yang sudah ditetapkan. Geser model untuk melihat dari berbagai sisi; gunakan tombol jika tidak menggunakan mouse atau sentuhan.
